# GiftOffer — оформление профиля

Предлагаемое отображаемое имя: **GiftOffer | NFT-сделки**

Варианты username для проверки в @BotFather (доступность не гарантируется):

- `GiftOfferMarketBot`
- `GiftOfferDealsBot`
- `GiftOfferNFTBot`

## Short description

🎁 Офферы на Telegram-подарки и NFT: сделки, резерв баланса и статусы выплат.

## Description

🎁 Создавай офферы на Telegram-подарки и NFT — прямо в нужном чате командой `/offer` через «Автоматизацию чатов».

🤝 Продавец принимает или отклоняет предложение; при принятии бот проверяет и резервирует баланс покупателя.

🔎 Продавец отправляет NFT на @staroffers_bank и нажимает кнопку подтверждения прямо в чате. Администратор вручную проверяет фактическое получение и отмечает выплату Stars.

👤 В профиле — баланс, статистика и история сделок.

🧩 Подписка расширяет дневную квоту запросов парсера.

💳 Пополнение: Stars на @walooon или Crypto Pay, если он подключён.

⚠️ Резерв — внутренний учёт сервиса, а не блокировка Stars в Telegram. Выплаты и проверка передачи выполняются администратором.

Этот сервис не является официальным продуктом Telegram.

## Suggested bot commands

- `/start` — главное меню
- `/admin` — админ-панель
- `/credit` — начислить или снять внутренний баланс
- `/ledger` — журнал баланса пользователя
- `/grant` — выдать расширенный доступ
- `/block` — заблокировать пользователя
- `/unblock` — восстановить доступ
- `/note` — добавить примечание к сделке/оплате

## Настроить через @BotFather

Для самого бота в @BotFather выбери **Bot Settings → Edit Name**, **Edit Description**, **Edit About** и **Edit Commands**. Username изменяется отдельно через настройки бота, если выбранное имя свободно.

Для основного бота, публикующего офферы и обслуживающего баланс, настрой connected-bot/Chat Automation в @BotFather и добавь `MTPROTO_API_ID` и `MTPROTO_API_HASH` в секреты сервера. Пользователь подключает этот Offers-бот в Telegram → Настройки → Автоматизация чатов, затем отправляет `/offer https://t.me/nft/Example-123 100` прямо в личном чате с продавцом. Групповые команды обслуживает отдельный второй бот.
