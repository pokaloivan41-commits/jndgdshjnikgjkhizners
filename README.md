# GiftOffer | NFT-сделки — версия 2.18

Telegram-бот для офферов на покупку NFT-подарков, внутреннего учёта Stars-баланса и админ-проверки выплат.

## Что уже реализовано в коде

- Цветные inline-кнопки Telegram: зелёные действия, красный отказ, синие основные действия.
- Число офферов не ограничено для всех пользователей. Бесплатный тариф включает 3 запроса парсера в день.
- Три платных тарифа на 30 дней: «Старт» — 19 ⭐ за 15 запросов парсера/день; «Плюс» — 39 ⭐ за 50 запросов/день; «Про» — 79 ⭐ за 150 запросов/день. Цены, сроки и квоты парсера меняются в админ-панели.
- Создание оффера: публичная ссылка на NFT и цена в ⭐-единицах. NFT по каждому офферу отправляется на фиксированный аккаунт сервиса **@staroffers_bank**; username в запросе не нужен.
- Два бота с общим SQLite-балансом: `BOT_TOKEN` обслуживает офферы, баланс, платежи и админ-панель, `GROUP_BOT_TOKEN` — только групповые команды и бонусы. Offers-бот подключается владельцем профиля через **Настройки → Автоматизация чатов**; команда `/offer` отправляется владельцем прямо в личном чате с продавцом. Inline Mode офферы не создаёт.
- Сообщение в выбранном чате показывает NFT-ссылку, сумму и фиксированный адрес передачи **@staroffers_bank**; Telegram формирует предпросмотр страницы. Под сообщением — кнопки «⊗ Отклонить» и «✓ Принять». После передачи продавец нажимает подтверждение в том же чате; администратор проверяет получение вручную.
- Продавец принимает/отклоняет оффер; при принятии бот атомарно проверяет баланс покупателя и сразу резервирует цену. Если денег не хватает, принятие не фиксируется.
- Офферы не имеют дневного лимита. Для нового оффера по-прежнему нужен достаточный доступный баланс; дневная квота сохраняется только у парсера.
- Продавец нажимает «✅ Подтвердить передачу» и присылает ссылку на переданный NFT. Ссылка сохраняется в сделке и отправляется администратору; участники могут открыть спор, резерв сохраняется до решения.
- Не принятые за заданное время офферы истекают; уже зарезервированные средства автоматически не освобождаются — бот напоминает администратору, чтобы не снять резерв после фактической передачи подарка.
- Администратор подтверждает получение, вручную отправляет Stars через второй сервис и отмечает выплату. После этого покупатель может оценить продавца.
- Пополнение Stars на username с ID операции и ручным решением администратора; отдельный Crypto Pay-счёт на каждый платёж и автоматическая проверка оплаты.
- Компактная админ-панель: **Выплата по офферу**, **Баланс/пополнения**, **Оферы** и раздел «Ещё». Офферы разбиты на отправленные, принятые и отклонённые; каждая запись открывает полную карточку с участниками, NFT, суммой, статусом и временем по МСК. Пополнения и выплаты подтверждаются администратором.
- В админке пользователя можно найти по Telegram ID или @username, увидеть профиль и постраничную историю офферов со ссылками, начислить/списать внутренние ⭐, заблокировать/разблокировать, выдать подписку и настроить квоту парсера. Большие списки для массовых операций загружаются CSV/TXT без лимита в 40 записей; интерфейс выбора постраничный. Действия журналируются.
- Кнопка **🧩 Парсер** доступна всем пользователям; её дневная квота входит в тариф. Парсер разбирает публичную ссылку `t.me/nft`, показывает владельца так, как его указал Telegram, или фильтрует ранее открытые карточки по владельцу, названию/коллекции, номеру, `Model`, `Backdrop`, `Symbol` и редкости. Имя владельца на странице может не быть username. Это не поиск по всем держателям коллекции: полного каталога/API владельцев и проверенных рыночных цен нет.
- Кнопка **👤 Профиль** показывает баланс, сделки и рейтинг; внутри — **📋 Мои сделки** со статусами и ссылками. Также доступны ID, помощь и правила/безопасность с контактом @walooon.
- Групповой бот приветствует нового участника с упоминанием, показывает короткое сообщение о закреплённой информации и, если акция включена, кнопку бонуса. Администратор может опубликовать/обновить постоянную кнопку из админ-панели. Сумма и интервал настраиваются; начисления списываются из пополняемого резерва кампании. Команды `/day`, `/week`, `/month` показывают лидеров по числу отправленных офферов за последние 24 часа, 7 и 30 дней по МСК; `/help` показывает краткую справку. Ответы группового бота удаляются автоматически при наличии у него права удалять сообщения.
- SQLite сохраняет пользователей, сделки, платежи, журнал баланса, рейтинги и действия администраторов. База автоматически копируется ежедневно, по умолчанию хранятся последние 7 дней резервных копий; логи ротируются и не содержат токенов.

## Быстрый запуск на Windows

1. Установи Python 3.10 или новее с опцией Add Python to PATH и распакуй архив в отдельную папку.
2. Дважды щёлкни `run_bot.bat`. При первом запуске откроется файл `.env` в Блокноте. Вставь токены **обоих** ботов, API ID и API Hash из my.telegram.org, числовой Telegram ID администратора и username получателя пополнений; ID группы необязателен. Сохрани файл и закрой Блокнот.
3. Скрипт установит зависимости, проверит настройки и запустит оба бота в одном окне. Если обнаружены ошибки, Блокнот откроется снова. Чтобы позже изменить настройки, запусти `setup_bot.bat`, затем `run_bot.bat`. Не отправляй файл `.env` никому: в нём секреты. При переносе старого проекта береги существующую базу и `.env`: не удаляй их и сделай резервную копию.

Окно консоли должно оставаться открытым. Для остановки нажми `Ctrl+C`. Нужен Python 3.10+.

## Подготовка настроек

Если заполняешь файл вручную, назови его строго `.env` (не `.env.txt`) и используй формат `КЛЮЧ=значение`, без слов `set` и без пробелов вокруг `=`. Пример:

```dotenv
BOT_TOKEN=сюда_токен_бота_баланса
GROUP_BOT_TOKEN=сюда_токен_второго_бота
MTPROTO_API_ID=числовой_api_id
MTPROTO_API_HASH=секретный_api_hash
BONUS_GROUP_ID=
ADMIN_IDS=твой_числовой_Telegram_ID
STAR_RECEIVE_USERNAME=твой_username_без_собаки
CRYPTOPAY_TOKEN=
USDT_PER_STAR=0
OFFER_TTL_HOURS=48
BACKUP_RETENTION_DAYS=7
DATABASE_PATH=offers.sqlite3
```

- `BOT_TOKEN` — **новый** токен, созданный после отзыва ранее опубликованного.
- `ADMIN_IDS` — числовой Telegram ID администратора; несколько ID через запятую. Узнать свой ID можно через надёжного бота наподобие @userinfobot; ник с `@` сюда не подходит.
- `STAR_RECEIVE_USERNAME` — username получателя Stars без `@`.
- `CRYPTOPAY_TOKEN` — токен приложения Crypto Pay. Можно оставить пустым, пока криптооплата не подключена.
- `USDT_PER_STAR` — начальный внутренний курс одной ⭐-единицы в USDT; `0` выключает Crypto Pay до настройки.
- В админ-панели **🧾 Тарифы и квоты парсера** меняются цена, срок и дневная квота парсера каждого тарифа. Число офферов не ограничено. В **⚙️ Настройках сервиса** меняются срок оффера, пауза новых офферов и курс Crypto Pay. Команда `/rate 100 1.50` задаёт курс: 100 внутренних единиц за 1.50 USDT; `/rate off` отключает криптооплату. Настройки сохраняются в SQLite; постоянный Railway Volume нужен, чтобы не потерять их при redeploy.

В `run_bot.bat` эти настройки проверяются; при неполном `.env` он выдаёт понятную подсказку.

Запуск:

```bash
python bot.py
```

### Где кнопка и как создать оффер в чате

Сначала открой бот баланса и нажми **Start**, чтобы получать уведомления. В Telegram подключи Offers-бота к профилю через **Настройки → Автоматизация чатов**, разреши отвечать в целевых личных чатах, затем прямо в чате с продавцом отправь: `/offer https://t.me/nft/Example-123 100`. Карточка появится в этом же чате. NFT всегда отправляется на **@staroffers_bank**; username получателя вводить не нужно. Группы не поддерживаются. Для MTProto-подключения оператору нужны `MTPROTO_API_ID` и `MTPROTO_API_HASH` из my.telegram.org и включённая поддержка connected bots у Offers-бота в @BotFather; это не требует превращать личный профиль пользователя в Telegram Business аккаунт.

Продавец прямо в сообщении нажимает **✓ Принять** или **⊗ Отклонить**. При принятии бот повторно проверяет и атомарно резервирует баланс покупателя. Продавец отправляет NFT на **@staroffers_bank**, нажимает **✅ Подтвердить передачу** и присылает ссылку на переданный NFT. Скриншот не нужен.

### Админ-панель

Администратор может открыть её командой **`/admin`** или кнопкой **🛠 Админ-панель**; доступ только у ID из `ADMIN_IDS`. Главное меню компактное: **Выплата по офферу**, **Баланс/пополнения**, **Оферы**, **Ещё**. В поиске пользователя введи ID/@username или загрузи CSV/TXT со списком без лимита в 40 записей. Выбор постраничный; можно выделить всех и одинаково начислить/списать ⭐ или выдать подписку. В **Настройки → Групповой бонус** задаются размер и интервал бонуса, а также резерв кампании. Для профильных офферов укажи `MTPROTO_API_ID` и `MTPROTO_API_HASH`. Для группы укажи `GROUP_BOT_TOKEN` и `BONUS_GROUP_ID` в `.env`; добавь группового бота администратором в группу. Для бонуса в админке установи сумму/интервал, переведи свои доступные внутренние ⭐ в резерв, включи акцию и нажми **Создать / обновить кнопку в группе**. Команды статистики считают отправленные офферы (создатель — покупатель оффера), исключая черновики. Для проверки Crypto Pay: **Настройки → Crypto Pay → Проверить подключение**.

## Админ-команды

- `/admin` — центр управления и очереди.
- `/rate` — посмотреть или изменить курс Crypto Pay; пример: `/rate 100 1.50`.
- `/export` — получить ZIP с CSV-отчётами пользователей, сделок, платежей, журнала баланса и действий админов. Архив содержит конфиденциальные данные — храни безопасно.
- `/credit <user_id или @username> <сумма>` — изменить внутренний доступный баланс; отрицательная сумма снимает баланс, но не больше доступной части.
- `/ledger <user_id или @username>` — посмотреть журнал начислений, резервов, возвратов и выплат.
- `/grant <user_id или @username> <дни>` — выдать/продлить подписку с повышенной квотой парсера.
- `/block <user_id или @username>` и `/unblock <user_id или @username>` — ограничить/вернуть доступ.
- `/note offer|payment <id> <текст>` — сохранить примечание к сделке или платежу.

## Финансовая логика и ограничения

- Баланс и резерв — внутренний реестр сервиса. Это не блокировка Stars на стороне Telegram.
- Stars, отправленные на username, нельзя автоматически подтвердить самим ботом в этой версии: пользователь сообщает ID операции, администратор сверяет платёж и одобряет заявку.
- Crypto Pay создаёт отдельный счёт с `payload` для связи с пользователем/платежом; бот проверяет его статус через API.
- После проверки подарка администратор вручную отправляет продавцу Stars через второй сервис, затем фиксирует выплату.
- USDT-эквивалент не является официальным курсом Telegram Stars; владелец задаёт внутренний курс командой `/rate` по текущей цене своего пакета. Это не официальный и не автоматически обновляемый курс Telegram.
- Никогда не публикуй `BOT_TOKEN` или `CRYPTOPAY_TOKEN`. Не отправляй токены в чат.

## Перед реальным запуском

Нужно установить собственные секреты в `.env`, указать администратора, username Stars-получателя и курс USDT, подключить Crypto Pay app token и проверить платежи в тестовой среде. `run_bot.bat` запускает бота локально — он будет работать, пока открыт компьютер и окно. Для работы 24/7 нужен VPS или другой постоянно работающий хостинг.

### Назначение администраторов через бота

Главный администратор с Telegram ID из `ADMIN_IDS` в личном чате **бота баланса** открывает `/admin` → «Администраторы» или использует команды `/addadmin 123456789`, `/deladmin 123456789` и `/admins`. Указывайте числовой Telegram ID, не username. Новый администратор получает полный доступ к админ-панели, включая баланс и сделки. Управлять администраторами могут только ID из `ADMIN_IDS`; их нельзя удалить командами бота. Назначения сохраняются в SQLite и переживают перезапуск при сохранении базы. Для уведомлений и работы с ботом новому администратору нужно открыть его и нажать Start. Групповой бот использует ту же базу; команды управления доступом находятся в основном боте баланса.

### Оформление и устойчивость профильных офферов

Новый профильный `/offer` отправляет **текстовую карточку** с названием, ссылкой, ценой, получателем и кнопками; по ссылке Telegram может показать своё превью NFT. Это не прежняя нарисованная картинка из `offer_preview.png`: вид превью и цвет кнопок зависит от клиента Telegram. Премиум-стикеры для карточки не нужны. После принятия карточка обновляется и предлагает кнопку подтверждения передачи прямо в чате; если редактирование не удалось, бот пробует отправить отдельное сообщение. Нажатие кнопки — заявление продавца, а не доказательство получения; администратор проверяет получение NFT самостоятельно.

При временной ошибке первичного подключения к Telegram основной бот повторяет попытку, а подключение профильного бота и групповой polling работают под отдельными циклами восстановления с задержкой. Это не гарантия работы без перерывов: неверные токены/права, остановка хостинга, конфликт второго экземпляра и сетевые проблемы требуют устранения причины. Используйте **одну** копию приложения для каждого токена и постоянный том для базы и MTProto-сессии. Нельзя гарантировать, что команда владельца `/offer`, отображение карточки и кнопки работают на всех версиях Telegram без реального теста на тестовых аккаунтах. До такого теста не используйте реальные деньги или подарки.

Локальные автономные проверки: `python -m unittest discover -s tests -v`. Они используют тестовую БД и заглушки Telegram, не заменяют проверку реального API или платежей.

### Переход с предыдущей версии

Теперь подключайте к профилю **основного оффер-бота** (`BOT_TOKEN`), а не группового бота. Для MTProto создан новый файл сессии `offers_main_bot.session`; старая сессия группового бота не переиспользуется. Перед обновлением остановите старый экземпляр и сохраните копию базы, .env и сессий. Старые профильные карточки, созданные другим ботом, могут перестать отвечать на кнопки: не удаляйте активные сделки и разберите их вручную, новые офферы создавайте заново после проверки. Балансы и история остаются в существующей базе; не заменяйте её пустой. Проверка с настоящим Telegram ещё необходима.

### Групповой бонус из личного чата с групповым ботом

Напиши **групповому боту** `/start` или `/admin` в личных сообщениях и выбери «🎁 Настроить бонус». Меню доступно только администраторам сервиса (ID в `ADMIN_IDS` или добавленные главным администратором через оффер-бота), а не автоматически всем администраторам Telegram-группы. Настрой сумму и интервал, пополни резерв из своего внутреннего баланса, включи акцию и нажми «Создать / обновить кнопку в группе». Для публикации укажи `GROUP_BOT_TOKEN` и `BONUS_GROUP_ID`, добавь бота в группу и разреши ему отправлять сообщения. Участники получают бонус в группе; он зачисляется на внутренний баланс, а не отправляется как Telegram Stars. Настройки также доступны в личной админ-панели оффер-бота. После смены настроек окружения перезапусти приложение.

### Профиль в групповом боте

В личном чате с групповым ботом открой `/start` → «Мой профиль» или отправь `/profile`. Видны Telegram ID, username, внутренний доступный баланс, резерв и число созданных офферов. Баланс общий с оффер-ботом; это не Telegram Stars. Если пользователь — администратор сервиса, в меню доступна настройка акции «Пополнение баланса». Прежняя бонусная механика не изменена: начисление идёт из резерва, по интервалу и только в выбранной группе. Команда `/bonus` сохранена для совместимости. Чтобы изменить уже опубликованную карточку в группе, администратор нажимает «Создать / обновить кнопку в группе».
